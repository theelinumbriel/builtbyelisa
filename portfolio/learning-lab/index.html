Highlights

TS 280: Python notebooks

Developed a suite of notebooks, including simple chat completions with GPT + ElevenLabs API to input a text, choose a target language, and output audio in that language, alongside more conceptual notebooks:

  • Ping-pong: repeatedly translating from language A to language B and tracking the convergence of the translation;
  • Telephone: translating from language A to B to C to D and then to the target language, evaluating how the intermediary translations impact the output;
  • Thematic focus + iteration: built with a professional translator to mimic his process. A first set of completions creates "context" strings focused on cultural context, authorship, and etymology; those strings + the original text are passed through a completion that returns a structured output with the translation and its strengths and weaknesses. Context + the three outputs are then iterated, so completion t corrects the weakness of completion t−1. The final translation is compared to a canonical, human translation. Final output = final translation + JSON of strengths/weaknesses of each intermediate translation + comparison to the canonical.

GENED 1196: Python notebooks

Prototyped an "AI-proof" oral assignment. Generated visuals (tarot cards with imagery + titles tied to core concepts, approaches, and case studies); prototyped a Next.js file using the OpenAI Realtime API to stream audio from student responses and generate follow-up questions live. A selection mechanism produced an initial series of follow-ups, a "judge" picked the top three, and a RAG chat completion over the syllabus + rubric chose what most needed elaboration based on the top follow-ups and the course material.

MUSIC 250HFA: Python notebooks

Developed a suite of notebooks using librosa and matplotlib to visualize musical snippets with 2D and 3D spectrograms, and to compare audio across different covers of the same song, e.g. visualizing how far different musicians emphasize different syllables in the same lyric.

MOD HEB 241R: Python notebook

Built a notebook using OpenAI chat completions with structured outputs and OpenAI's Whisper API to help students edit videos. The notebook took a prompt, e.g. "discussions of environmental policy", and output a cut of every snippet where the video matched the prompt.
